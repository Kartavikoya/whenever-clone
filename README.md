# Whenevr — Design Subscription Landing Page

A modern, high-performance landing page built with **Next.js 14**, **Tailwind CSS**, and **Framer Motion**, inspired by premium SaaS design systems.

---

## Features

* Smooth scroll-based animations (Framer Motion)
* Horizontal showcase section (Framer-style interaction)
* Fully responsive (mobile → desktop)
* Clean UI with modern typography
* Optimized with Next.js App Router
* Image optimization using `next/image`
* Page loader & micro-interactions

---

## Tech Stack

* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Fonts:** `next/font` (Inter + Source Serif)
* **Deployment:** Vercel (recommended)

---

## Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/your-username/whenevr.git
cd whenevr
```

### 2. Install dependencies

```bash
npm install
# or
yarn install
# or
pnpm install
```

### 3. Run development server

```bash
npm run dev
```

Open http://localhost:3000
